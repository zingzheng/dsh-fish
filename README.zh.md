# dsh-fish

[English](README.md) | 中文

**dsh摸鱼小组件：** 在 DSH 输入框上方以思考行样式显示自选股票行情，或阅读 TXT/EPUB 电子书。

它是一个只面向人的界面：整行由客户端渲染，不是会话事件，不影响真实对话或模型输出。插件不注册模型工具，也不注入提示词。

目前有两个应用共用这一行：

- **股票** — 看起来像一行思考的自选行情。
- **阅读** — 书存放在 DSH 主机上的 TXT/EPUB 阅读器，进度保存在主机；刷新页面或换浏览器都能继续。

## 安装

要求：

- 带 Web UI 的 DeepSeek Harness（插件是 `dsh.bundle`）。
- 主机 Node.js 20 或更新。

从 GitHub 安装：

```sh
dsh plugin --profile web add github:zingzheng/dsh-fish
```

安装后重启 DeepSeek Harness，让 Host 端和客户端 bundle 生效。

开发时可直接链接工作副本：

```sh
dsh plugin --profile web add link:/path/to/dsh-fish
```

然后打开一个会话，运行 `/fish`。

## 使用

- `/fish` — 打开 fish 应用选择器。
- `/fish stock` — 直接打开股票行情。
- `/fish novel` — 直接打开阅读。
- `/fish off` — 关闭当前会话的 fish 行。
- `/fish status` — 显示当前应用。

`/fish`、`/fish stock` 和 `/fish novel` 是 Host 命令。单独的 `/fish` 选择器还会被客户端装饰成弹窗；在那里选择应用不会写入命令事件。直接命令会作为普通命令行出现在会话里。

### 股票行情

- 收起：一行看起来像思考的行情，显示当前聚焦的代码。
- 点击这一行可聚焦。按 `E`（或点箭头）展开；只点行本身不会打开面板。
- `R` 立即刷新；`J` / `K`（或方向键与 `[` / `]`）切换聚焦代码；`1`–`9` 跳到对应代码。
- 聚焦时按 `Esc` 收起。
- 默认每 5 分钟刷新一次，间隔可配置。

### 阅读

在 **设置 → fish → 阅读** 导入书籍。文件会传到 DSH 主机并存放在 `$DSH_HOME/fish` 下；不会发送给模型，也不会写入会话日志。

- **收起 = 单行**。整行只显示当前书的一行视觉文本。长行自然换行；每次翻页移动一行。不显示书名、章节名、页码或书籍相关的悬停提示。
- **展开 = 多行**。默认每页 10 行视觉文本（可配置 6–14 行）。翻页移动一个视口；自动翻页仍然每次移动一行。
- **内容锚点**。进度保存为字符位置，不是页码。改变字号、每页行数、窗口宽度或收起行之后，回到同一段文字，而不是同一个页码。
- **每本书独立**。每本书保留自己的位置；切到另一本再回来，会从上次的位置继续。
- **跨浏览器**。书籍、当前书和进度都在 DSH 主机上。同一主机上的第二个浏览器会看到同一个书架和同一个位置。
- **没有空白页**。导入时会合并段落之间的空行，单行翻页不会停在空白页上。
- **自动翻页**。每次计时移动一行；标签页隐藏时暂停，被老板键隐藏时也暂停。
- **鼠标滚轮**。指针在阅读行上时，滚轮移动一行；书架列表不拦截滚轮。

支持格式：

- **TXT** — UTF-8、UTF-16LE / UTF-16BE（BOM）和 GB18030。
- **EPUB** — ZIP（stored / deflate）、`container.xml`、OPF spine、NCX 和 EPUB3 导航、XHTML 正文。图片、CSS、脚注和 DRM 不渲染；受 DRM 保护的 EPUB 会被拒绝。
- 会去掉 Project Gutenberg 的 header/license 块。Gutenberg 那种由纯文本生成的 EPUB，会按正文自己的中文回目标题重新切章，而不是当成十几个随意的 XHTML 块。
- **不支持**：PDF、MOBI、AZW3、在线书源。这些需要专门的格式基础设施，不适合放进这个小应用。

主机限制：单个上传文件 64 MB、解析后正文 2000 万字符、EPUB 解压后 64 MB、5000 章。

### 阅读快捷键

阅读面板打开时，全局快捷键可用，即使输入框有焦点。它们至少需要一个 `Ctrl` / `Alt` / `Cmd` 修饰键。

| 操作 | 全局 | 阅读行有焦点时 |
| --- | --- | --- |
| 下一页 / 上一页 | `Alt + J` / `Alt + K` | `J` / `K`、`→` / `←`、`↓` / `↑`、`Space` / `Shift + Space`、`PageDown` / `PageUp` |
| 下一章 / 上一章 | `Alt + N` / `Alt + P` | `N` / `P` |
| 下一本 / 上一本 | `Alt + ]` / `Alt + [` | `]` / `[` |
| 打开书库 | `Alt + L` | `L` |
| 开关自动翻页 | `Alt + O` | `A` |
| 展开 / 收起 | `Alt + G` | `E` / `Enter` |
| 隐藏 / 恢复 | `Alt + H` | — |

每个绑定都能在 **设置 → fish → 阅读** 里重新录制。书架列表里用 `J` / `K` 或方向键移动选择，`Enter` 打开，`Esc` 返回阅读。

### 全局快捷键

任何 fish 面板打开时，全局快捷键可用，即使输入框有焦点。它们始终至少需要一个 `Ctrl` / `Alt` / `Cmd` 修饰键，避免捕获普通输入。

默认：

- 隐藏 / 恢复：`Alt + H`
- 展开 / 收起：`Alt + G`

每个绑定都能在 **设置 → fish → 全局** 里重新录制。老板键动作也会关闭打开的选择器；隐藏会发送到 Host，所以刷新页面不会把面板带回来。

## 设置

设置页有一个 **全局** 标签，以及每个 fish 应用一个标签：

- **全局** — 隐藏/恢复、展开/收起快捷键。
- **股票** — 自选列表、股票快捷键、刷新间隔和颜色（红涨绿跌、绿涨红跌或不作色）。
- **阅读** — 书籍导入 / 书架 / 删除、字号、每页行数、自动翻页间隔和阅读快捷键。

股票自选支持 A 股（`600519` / `sh600519`）、港股（`00700` / `hk00700`）、美股（`AAPL` / `usAAPL`、`usBRK.B`）和指数（`sh000001`、`hkHSI`、`usDJI`、`usIXIC`、`usINX`），最多 12 个代码。裸代码如 `AAPL` 按美股处理；`SPX` 映射到 `usINX`。

股票和阅读的界面设置保存在浏览器 `localStorage`。书籍和阅读进度不在这里：它们保存在 DSH 主机的 `$DSH_HOME/fish/library.json` 和 `$DSH_HOME/fish/books/<sha256>.json`。

## 主机数据

```text
$DSH_HOME/fish/
├── library.json              书架、当前书、每本书的进度
└── books/
    └── <sha256>.json         一本书解析后的章节
```

书架最多保留 100 本书。再次导入相同字节会更新最后打开时间，并保留已有进度。删除一本书会删除解析内容和书架记录；没有原始文件需要删除。

## 隐私与边界

- 书籍正文不会进入会话、会话日志或模型上下文。浏览器只通过需要认证的同源路由读取章节。
- 股票行情由 Host 从 `qt.gtimg.cn` 和 `web.ifzq.gtimg.cn` 拉取；浏览器不会直接请求这些第三方端点。
- 上传文件保存在 `$DSH_HOME/fish` 下，权限仅所有者可读写。通过设置删除书籍会从主机移除解析内容。

## 开发

```sh
npm test
```

测试覆盖 TXT 解码（UTF-8、UTF-16LE/BE、GB18030）、EPUB 解析、章节切分、Project Gutenberg 清理、进度计算和主机书架。

在运行中的 Harness 里试用本地副本：

```sh
dsh plugin --profile web add link:$PWD
```

然后重启 Harness。profile 里是链接，所以代码改动后需要重新加载插件，而不是重新安装。

## 文件

- `index.js` — Host 端：`/fish` 命令、每会话应用状态、行情代理、书籍导入 / 书架 / 章节 / 进度路由。
- `book.js` — TXT 解码和章节切分。
- `epub.js` — 无依赖的 EPUB ZIP / OPF / NCX / 导航解析器。
- `books.js` — Host 端书架、内容文件和进度持久化。
- `client.js` — 浏览器端：思考行、股票面板、阅读面板、设置标签、快捷键录制、命令选择器和全部样式。
- `test/novel.test.js` — TXT/EPUB 解析、章节切分、进度计算和主机书架的 Node 测试。
- `cordis.patch.yml` — 插入插件的 bundle patch。
- `locale/*.json` — 插件管理器元数据。
- `icon.svg` — 原始插件图标。
- `README.md` / `README.zh.md` — 英文 / 中文说明。

## 说明

- Host 同时请求 `qt.gtimg.cn` 快照和 `web.ifzq.gtimg.cn/appstock/app/minute/query` JSON feed。它会比较两边的交易所时间戳并保留更新的那个，因为快照端点可能滞后，而分钟 feed 内嵌的 `qt` 数组是当前值。两个 feed 都通过 Host 代理，浏览器不需要跨域访问或 GBK 解码。
- 行情代理支持 A 股、港股、美股和指数，也支持混合自选列表。
- 港股成交量单位是股、成交额是 HKD；美股是股和 USD；A 股是手和 CNY。面板会格式化这些单位，并在详情行显示币种。
- 美股行情时间从 `America/New_York` 转换（处理夏令时）；美股交易时段按纽约时间 09:30–16:00 显示为 live。
- 当前应用保存在 Host 内存里，按会话区分。刷新页面会保留，Host 进程重启不会。
- 书籍正文只通过需要认证的同源路由读取。插件不注册模型工具或提示词；书籍正文不会进入会话或模型上下文。
